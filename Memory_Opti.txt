2) RECOMMENDATION — MOVE SQL FEEDS OFF MAKE (ETL -> ELT)
   - Reframe: Make does ETL (transform-in-flight). Target = ELT:
       EXTRACT raw Intacct -> SQL staging; TRANSFORM in SQL views/stored procs;
       LOAD staging -> final via atomic swap (crash-safe; fixes the naive
       DELETE-then-insert that can leave tables half-empty on failure);
       ORCHESTRATE via SQL Server Agent / ADF (replaces Make scheduler + sleeps).
   - The 26+5 date-slicing and 30s sleeps DISAPPEAR (one windowed SELECT/query).
