# docs/design/ — Per-wave design notes (WAVES step **A**)

One file per wave, e.g. `W0_design.md`, `W1_design.md`. Each records: components/interfaces/SQL for
the slice, data flow, config keys used, decisions made, spec/open-question updates implied, and how the
design traces back to `../../specs/`. Written and user-checked before any code (WAVES `A` gate).
